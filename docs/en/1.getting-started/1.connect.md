## Join the game

1. Start Minecraft: Java Edition **26.3**. **26.2** is also supported.
2. Open **Multiplayer** and add a server.
3. Enter `sirargon.net` as the address and connect.

## With or without mods

You can play without the voice mod. To talk to others in game, use the official [Sirargons Mod-Mische](https://modrinth.com/modpack/sirargons-mod-mische) modpack. Simple Voice Chat is included.

Read more about [voice chat](/guides/voice-chat).
