Milestones are one-time goals on the SMP. Each one pays silver once. The Overworld, the Nether and the End have their own milestones. `/milestones` shows them: choose the realm at the top; reached milestones are darker.

## Overworld

### Start

| Milestone          | Task                          |       Reward |
| :----------------- | :---------------------------- | -----------: |
| First steps        | Open `/skills`.               |   200 Silver |
| First star         | Spend your first skill point. |   500 Silver |
| Own camp           | Found a [camp](/smp/camps).   | 1,000 Silver |
| First quest        | Complete a daily quest.       |   300 Silver |
| Weekly work        | Complete a weekly quest.      | 1,000 Silver |
| Through the portal | Enter the Nether.             | 1,000 Silver |

Only Overworld quests count for **First quest** and **Weekly work**.

### Level

| Milestone    | Task                                   |        Reward |
| :----------- | :------------------------------------- | ------------: |
| SMP level 5  | Reach SMP level 5.                     |  1,000 Silver |
| SMP level 10 | Reach SMP level 10.                    |  2,000 Silver |
| SMP level 20 | Reach SMP level 20.                    |  5,000 Silver |
| SMP level 30 | Reach SMP level 30.                    | 10,000 Silver |
| Level 40     | Collect 11,650 SMP XP, about level 40. | 10,000 Silver |
| Level 50     | Collect 19,550 SMP XP, about level 50. | 10,000 Silver |

More on XP and levels under [Levels and XP](/smp/skills#levels-and-xp).

### Special places

For these milestones, you discover the place and earn its advancement.

| Milestone        | Task                     |        Reward |
| :--------------- | :----------------------- | ------------: |
| Pillager outpost | Find a pillager outpost. |  5,000 Silver |
| Ocean monument   | Find an ocean monument.  |  5,000 Silver |
| Ancient city     | Find an ancient city.    |  5,000 Silver |
| Trial chambers   | Find trial chambers.     |  5,000 Silver |
| Woodland mansion | Find a woodland mansion. | 10,000 Silver |

## Nether

You see the Nether milestones once you play actively in the Nether for the first time, for example by breaking a block or fighting.

| Milestone              | Task                                                                       |        Reward |
| :--------------------- | :------------------------------------------------------------------------- | ------------: |
| Fortress Found         | Enter a Nether fortress.                                                   |  1,000 Silver |
| Bastion Found          | Enter a bastion.                                                           |  1,000 Silver |
| First Blaze            | Defeat a blaze.                                                            |  1,000 Silver |
| Lava Rider             | Ride a strider.                                                            |  1,000 Silver |
| Ancient Find           | Mine ancient debris.                                                       |  2,000 Silver |
| Soul sand valley       | Discover the soul sand valley.                                             |  5,000 Silver |
| Basalt deltas          | Discover the basalt deltas.                                                |  2,000 Silver |
| Crimson forest         | Discover the crimson forest.                                               |  5,000 Silver |
| Warped forest          | Discover the warped forest.                                                |  5,000 Silver |
| All five Nether biomes | Visit all five vanilla Nether biomes.                                      | 10,000 Silver |
| Incendium discovery    | Discover a special Incendium place in the Nether and earn its advancement. |  5,000 Silver |

## End

You see the End milestones once you play actively in the End for the first time. Each one belongs to a vanilla End advancement. If you reached the advancement earlier, you get the silver afterwards.

| Milestone           | Task                                       |        Reward |
| :------------------ | :----------------------------------------- | ------------: |
| Through the gateway | Travel through an End gateway.             |  2,000 silver |
| End city            | Find an End city.                          |  5,000 silver |
| Up we go            | Rise 50 blocks with levitation.            |  5,000 silver |
| Dragon's breath     | Collect dragon's breath in a glass bottle. |  5,000 silver |
| Elytra              | Find elytra.                               | 10,000 silver |
| A new dragon        | Respawn an Ender dragon.                   | 10,000 silver |

## Commands

- `/milestones`: milestones
