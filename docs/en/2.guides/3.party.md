Use `/party` to open your party. A party keeps your group together for playing.

| Command                   | What it does                              |
| :------------------------ | :---------------------------------------- |
| `/party create`           | Create a party                            |
| `/party invite <player>`  | Invite a player; create a party if needed |
| `/party accept <player>`  | Accept an invitation                      |
| `/party decline <player>` | Decline an invitation                     |
| `/party list`             | Show members                              |
| `/party leave`            | Leave the party                           |
| `/party leader <player>`  | Pass on leadership if you lead the party  |
| `/party kick <player>`    | Remove a member if you lead the party     |
| `/party disband`          | Disband the party if you lead it          |

Use `/partychat <message>` to write in party chat. `/party help` shows more actions.
