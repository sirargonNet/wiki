A clan has its own name, tag and colour. You can only be in one clan at a time. Open yours with `/clan`, and discover other clans with `/clans`.

Founding a clan is free, but you need network level 5. The more clan XP you collect, the higher your clan levels up and the more members it has room for.

## Overview

This is what a clan brings you:

- Your clan's tag shows in colour after your name.
- You see who is online and on which server.
- You get your own clan chat with `/clanchat` or `/cc`.
- An announcement reaches all members.
- You can jump to members from the clan menu.
- You get a notice when members come online.

## Find clans

`/clans` opens the clan directory. Looking for a particular clan? `/clans search <text>` finds it from part of its name or tag. `/clans info <clan>` shows you a clan's join mode, member count, founding date and founder. You only see the member list if the clan shows it publicly.

## Join

How you get into a clan depends on its join mode:

- **Invitation only:** only the founder and officers can invite you. Accept the invitation with `/clan accept <clan>`, or decline it with `/clan decline <clan>`.
- **On request:** you send an application with `/clan apply <clan> [text]`, and the founder or officers decide on it. `/clan withdraw <clan>` takes it back.
- **Open:** anyone can join. `/clan join <clan>` gets you straight in.

To see your invitations, use `/clan invitations`.

- Invitations and applications expire after 7 days.
- You can have up to 5 open applications.
- An application can hold up to 200 characters of text. You can also leave it empty.
- The answer to your application arrives in your [messages](/guides/account#messages). If the clan turns you down in the clan menu, you see the reason: **Clan is full**, **Not a fit**, **Inactive** or **Other reason**.
- Once you join a clan, your other applications and invitations end.
- You can't join a clan that is full or has banned you.

In the [settings](/guides/settings#requests) you choose who may send you clan invitations. That setting only covers invitations to you; it doesn't limit the applications you send.

## Found a clan

1. `/clan create <tag> <name>` checks whether the tag and name are valid and still free.
2. `/clan found <tag> <name>` founds the clan.

You need:

- **Network level 5.** More about levels under [Currencies & streak](/guides/currencies#network-level).
- **No clan.** You must not be in another clan.
- **No waiting time.** If you disbanded a clan or left one as founder, you have to wait 7 days before you can found another. You can still join a clan during that time.

A new clan starts with the colour Aqua, the join mode **Invitation only** and a public member list. You can change all of that afterwards in the clan menu.

## Name and tag

| Rule       | Name                                     | Tag                    |
| :--------- | :--------------------------------------- | :--------------------- |
| Length     | 3 to 20 characters                       | 2 to 5 characters      |
| Characters | letters a to z, digits, spaces, - and \_ | letters a to z, digits |

- Spaces, `-` and `_` can never come at the start or end, or twice in a row.
- Upper and lower case don't matter: `ABC` and `abc` are the same tag.
- Every name and every tag exists only once, and offensive words are not allowed.
- The founder changes the name and tag with `/clan rename <name>` and `/clan tag <tag>`. After that, they have to wait 30 days before changing them again.
- After a rename, the old name and the old tag stay locked for 30 days. During that time, only your own clan may take them back.
- Once a clan is disbanded, its name and tag are locked for 30 days for everyone, the former founder included.

## Roles

There are three roles: **founder**, **officer** and **member**. Every clan has exactly one founder, who decides how many officers there are.

| Right                                | Member | Officer |  Founder   |
| :----------------------------------- | :----: | :-----: | :--------: |
| Clan chat, see members, follow       |   ✓    |    ✓    |     ✓      |
| Leave the clan                       |   ✓    |    ✓    | only alone |
| Invite players, withdraw invitations |        |    ✓    |     ✓      |
| Accept or decline applications       |        |    ✓    |     ✓      |
| Remove members                       |        |    ✓    |     ✓      |
| Remove officers                      |        |         |     ✓      |
| See and lift clan bans               |        |    ✓    |     ✓      |
| Set the announcement                 |        |    ✓    |     ✓      |
| See the clan log                     |        |    ✓    |     ✓      |
| Officer chat                         |        |    ✓    |     ✓      |
| Promote and demote officers          |        |         |     ✓      |
| Change name and tag                  |        |         |     ✓      |
| Change the colour                    |        |         |     ✓      |
| Change the join mode                 |        |         |     ✓      |
| Set the description                  |        |         |     ✓      |
| Show or hide the member list         |        |         |     ✓      |
| Hand over founding                   |        |         |     ✓      |
| Disband the clan                     |        |         |     ✓      |

**Member**

- leave the clan: `/clan leave`

**Officer**

- invite players: `/clan invite <player>`, withdraw with `/clan uninvite <player>`
- see applications: `/clan applications`
- accept or decline applications: `/clan applications accept <player>` or `/clan applications decline <player>`
- remove members: `/clan kick <player>`. Officers can only remove members. In an open clan, a removed member is also [banned](/guides/clans#bans).
- see and lift clan bans: `/clan bans`, `/clan unban <player>`
- set an announcement for all members: in the clan menu with `/clan`
- see the clan log: `/clan log`
- officer chat: `/officerchat` or `/oc`

**Founder**

- everything officers can do
- remove officers: `/clan kick <player>`
- change roles: `/clan promote <player>`, `/clan demote <player>`
- change name and tag: `/clan rename <name>`, `/clan tag <tag>`
- change colour: `/clan colour <colour>`
- change how players join: `/clan mode invite-only|request|open`
- set the description: `/clan description [text]`
- show or hide the member list: `/clan members-public on|off`
- hand over founding: `/clan transfer <player>`
- disband the clan: `/clan disband`

When you are promoted or demoted, you get a [message](/guides/account#messages). If you lose your officer role, the invitations you sent end.

## Bans

In an open clan, a removed member is banned automatically, so they can't come straight back. Banned players can neither join the clan nor apply to it. `/clan bans` lists all bans with their date, and `/clan unban <player>` lifts one.

## Announcement and description

- **Announcement:** a message for all members, up to 200 characters. It appears in the clan overview with its author and date. The founder and officers set it in the clan menu under **Settings**.
- **Description:** one sentence for the directory, up to 200 characters. The founder sets it with `/clan description <text>`, and `/clan description` without text removes it again.
- **Public member list:** with `/clan members-public on|off` the founder shows or hides the member list in the directory.

Links in these texts only work for allowed sites.

## Colour

The founder changes the colour with `/clan colour <colour>` or in the clan menu under **Appearance**. There are 10 colours:

- **Free:** `aqua` (Aqua), `mint` (Mint), `rosa` (Rosa), `orange` (Orange)
- **From the founder's rank Prime:** `amber` (Amber), `sky` (Sky blue), `coral` (Coral), `lime` (Lime), `ice` (Ice white), `lavender` (Lavender)

If the founder has at least the rank Prime, they can also turn on a **Gradient**, which makes the tag fade into a second colour. The gradient and the second colour can only be set in the clan menu under **Appearance**.

## Clan chat

- **Clan chat:** `/clanchat` or `/cc`, for all members
- **Officer chat:** `/officerchat` or `/oc`, only for the founder and officers

Add a message and it goes into the channel once. Leave it out and the channel becomes your default. See [Chat](/guides/chat).

## Clan level

Your clan collects clan XP while your members play actively, and climbs one level at a time. The clan menu shows your level and how much clan XP you still need for the next one. When your clan reaches a new level, every member who is online at the time gets a notice.

A [Clan XP booster](/guides/inventory#boosters) doubles Clan XP for every clan on the network, and players without a clan can buy and activate one too. Multiple Clan boosters run one after another.

## Clan statistics

In the SMP and in Creative, `/stats` also shows clan values. `/stats <statistic> clans` shows the clan ranking, and `/stats <statistic> clan [tag]` shows the values of one clan. Leave out the tag to see your own. See [Account](/guides/account#commands).

## Clan log

`/clan log` shows the founder and officers what happened in the clan, newest first:

- members who joined, left or were removed
- changed roles and handed-over founding
- reached clan levels and new member limits
- accepted and declined applications
- sent, withdrawn and declined invitations

## Leave, hand over, disband

- **Leave:** `/clan leave`. As founder, you can only leave when nobody else is in the clan, and the clan is then disbanded.
- **Hand over:** `/clan transfer <player>` makes a member the founder, and you stay in the clan as an officer.
- **Disband:** `/clan disband`. All members leave the clan, and its name and tag are locked for 30 days. You can found a new clan after 7 days.

## Commands

`<…>` and `[…]` are placeholders; `[…]` is optional, `a|b` means one of them.

### Find clans

- `/clans`: open the clan directory
- `/clans list`: show the directory
- `/clans search <text>`: search for a clan
- `/clans info <clan>`: information

### Join and found

- `/clan invitations`: your invitations
- `/clan accept <clan>`: accept an invitation
- `/clan decline <clan>`: decline an invitation
- `/clan apply <clan> [text]`: apply
- `/clan withdraw <clan>`: withdraw an application
- `/clan join <clan>`: join an open clan
- `/clan create <tag> <name>`: check tag and name
- `/clan found <tag> <name>`: found a clan

### Members

- `/clan`: open your clan
- `/clan info`: show your clan
- `/clan members`: show members
- `/clan leave`: leave the clan
- `/clanchat` or `/cc`: clan chat
- `/clan help`: all actions

### Officers

- `/clan invite <player>`: invite
- `/clan uninvite <player>`: withdraw an invitation
- `/clan applications`: show applications
- `/clan applications accept <player>`: accept an application
- `/clan applications decline <player>`: decline an application
- `/clan kick <player>`: remove a member
- `/clan bans`: show clan bans
- `/clan unban <player>`: lift a ban
- `/clan log`: clan log
- `/officerchat` or `/oc`: officer chat

Officers set the announcement for all members in the clan menu with `/clan`.

### Founder

- `/clan promote <player>`: promote
- `/clan demote <player>`: demote
- `/clan rename <name>`: change the name
- `/clan tag <tag>`: change the tag
- `/clan colour <colour>`: change the colour. Free: `aqua`, `mint`, `rosa`, `orange`. From the founder's rank Prime: `amber`, `sky`, `coral`, `lime`, `ice`, `lavender`.
- `/clan mode invite-only|request|open`: change how players join
- `/clan description [text]`: set the description
- `/clan members-public on|off`: show or hide the member list
- `/clan transfer <player>`: hand over founding
- `/clan disband`: disband the clan

`/clan join`, `/clan leave`, `/clan kick`, `/clan transfer` and `/clan disband` ask first. Add `confirm` at the end to skip the question, for example `/clan leave confirm`.

## Frequently asked questions

### How do I found a clan?

With `/clan found <tag> <name>`, as long as you have reached a certain network level. The details are under [Found a clan](/guides/clans#found-a-clan).

### How do I join a clan?

That depends on the clan: accept an invitation with `/clan accept <clan>`, apply with `/clan apply <clan>` or join directly with `/clan join <clan>`.

### How do I find a clan?

`/clans` opens the directory, and `/clans search <text>` searches it.

### Why can I not leave the clan?

As founder, you first have to hand over founding with `/clan transfer <player>` or disband the clan with `/clan disband`.

### Who may do what in the clan?

Members can leave the clan. Officers invite players, decide on applications, remove members, manage clan bans and set the announcement. The founder can do everything. More under [Roles](/guides/clans#roles).

### What happens when the founder stops playing?

They stay founder until they hand over founding or disband the clan. If their account is deleted, the officer who has been in the clan longest becomes founder. If there is no officer, the member who has been in the clan longest takes over.

### How does my clan get more room?

Your clan gains clan XP while you play. At certain clan levels more members fit in; the table under [Clan level](/guides/clans#clan-level) shows which.

### How do I change the colour or tag?

As founder, with `/clan colour <colour>` and `/clan tag <tag>`. 4 of the 10 colours are free; the other 6 need a founder with at least Prime. More under [Colour](/guides/clans#colour).
