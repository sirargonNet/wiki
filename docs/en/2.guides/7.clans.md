`/clan` opens your clan. `/clans` lets you discover other clans. A clan has a name, a tag and a colour. You can only be in one clan at a time.

Founding a clan is free and needs network level 5. With clan XP your clan levels up and gets room for more members.

## Overview

This is what a clan brings you:

- **Tag:** shown in colour after your name
- **See online:** who is online and on which server
- **Clan chat:** with `/clanchat` or `/cc`
- **Announcement:** a message for all members
- **Follow:** jump to members from the clan menu
- **Notices:** when members come online

## Find clans

`/clans` opens the clan directory. `/clans search <text>` searches for part of a name or tag. `/clans info <clan>` shows a clan's join mode, member count, founding date and founder. You only see the member list if the clan shows it publicly.

## Join

How you join depends on the clan's join mode:

- **Invitation only:** only the founder and officers invite. `/clan accept <clan>` accepts an invitation, `/clan decline <clan>` declines it.
- **On request:** you apply, the founder or officers decide. `/clan apply <clan> [text]` sends an application, `/clan withdraw <clan>` withdraws it.
- **Open:** anyone can join. `/clan join <clan>` joins directly.

`/clan invitations` shows your invitations.

- Invitations and applications expire after 7 days.
- You can have up to 5 open applications.
- An application text has up to 200 characters. You can also leave it empty.
- The answer to your application lands in your [messages](/guides/account#messages). If the clan declines in the clan menu, you see the reason: **Clan is full**, **Not a fit**, **Inactive** or **Other reason**.
- When you join a clan, your other applications and invitations end.
- If a clan is full or has banned you, you cannot join.

In the [settings](/guides/settings#requests) you choose who may send you clan invitations. Applications you send are never limited.

## Found a clan

1. `/clan create <tag> <name>` checks whether tag and name are valid and free.
2. `/clan found <tag> <name>` founds the clan.

You need:

- **Network level 5.** More about levels under [Currencies & streak](/guides/currencies#network-level).
- **No clan.** You must not be in another clan.
- **No waiting time.** If you disbanded a clan or left one as founder, you can found again after 7 days. You can still join a clan during that time.

Founding is free. A new clan starts with the colour Aqua, the join mode **Invitation only** and a public member list. You change that afterwards in the clan menu.

## Name and tag

| Rule       | Name                                     | Tag                    |
| :--------- | :--------------------------------------- | :--------------------- |
| Length     | 3 to 20 characters                       | 2 to 5 characters      |
| Characters | letters a to z, digits, spaces, - and \_ | letters a to z, digits |

- Spaces, `-` and `_` are never at the start or end and never twice in a row.
- Upper and lower case do not matter. `ABC` and `abc` are the same tag.
- Every name and every tag exists only once. Offensive words are not allowed.
- The founder changes name and tag with `/clan rename <name>` and `/clan tag <tag>`. After that, the next change is possible after 30 days.
- After a rename, the old name and the old tag are locked for 30 days. Only your own clan may take them back during that time.
- After a clan is disbanded, its name and tag are locked for 30 days for everyone, the former founder included.

## Roles

There are three roles: **founder**, **officer** and **member**. Every clan has exactly one founder. The founder decides how many officers there are.

| Right                                | Member | Officer |  Founder   |
| :----------------------------------- | :----: | :-----: | :--------: |
| Clan chat, see members, follow       |   ✓    |    ✓    |     ✓      |
| Leave the clan                       |   ✓    |    ✓    | only alone |
| Invite players, withdraw invitations |        |    ✓    |     ✓      |
| Accept or decline applications       |        |    ✓    |     ✓      |
| Remove members                       |        |    ✓    |     ✓      |
| Remove officers                      |        |         |     ✓      |
| See and lift clan bans               |        |    ✓    |     ✓      |
| Set the announcement                 |        |    ✓    |     ✓      |
| See the clan log                     |        |    ✓    |     ✓      |
| Officer chat                         |        |    ✓    |     ✓      |
| Promote and demote officers          |        |         |     ✓      |
| Change name and tag                  |        |         |     ✓      |
| Change the colour                    |        |         |     ✓      |
| Change the join mode                 |        |         |     ✓      |
| Set the description                  |        |         |     ✓      |
| Show or hide the member list         |        |         |     ✓      |
| Hand over founding                   |        |         |     ✓      |
| Disband the clan                     |        |         |     ✓      |

**Member**

- leave the clan: `/clan leave`

**Officer**

- invite players: `/clan invite <player>`, withdraw with `/clan uninvite <player>`
- see applications: `/clan applications`
- accept or decline applications: `/clan applications accept <player>` or `/clan applications decline <player>`
- remove members: `/clan kick <player>`. Officers can only remove members. In an open clan, a removed member is also banned.
- see and lift clan bans: `/clan bans`, `/clan unban <player>`
- set an announcement for all members: in the clan menu with `/clan`
- see the clan log: `/clan log`
- officer chat: `/officerchat` or `/oc`

**Founder**

- everything officers can do
- remove officers: `/clan kick <player>`
- change roles: `/clan promote <player>`, `/clan demote <player>`
- change name and tag: `/clan rename <name>`, `/clan tag <tag>`
- change colour: `/clan colour <colour>`
- change how players join: `/clan mode invite-only|request|open`
- set the description: `/clan description [text]`
- show or hide the member list: `/clan members-public on|off`
- hand over founding: `/clan transfer <player>`
- disband the clan: `/clan disband`

When you are promoted or demoted, you get a [message](/guides/account#messages). When you are demoted from officer, the invitations you sent end.

## Bans

In an open clan, a removed member is banned automatically. So they cannot join again right away. Banned players cannot join the clan or apply to it. `/clan bans` shows all bans with their date. `/clan unban <player>` lifts a ban.

## Announcement and description

- **Announcement:** a message for all members, up to 200 characters. It appears in the clan overview, with author and date. The founder and officers set it in the clan menu under **Settings**.
- **Description:** one sentence for the directory, up to 200 characters. The founder sets it with `/clan description <text>`. Without text, `/clan description` removes it.
- **Public member list:** with `/clan members-public on|off` the founder shows or hides the member list in the directory.

Links in these texts only work for allowed sites.

## Colour

The founder changes the colour with `/clan colour <colour>` or in the clan menu under **Appearance**. There are 10 colours:

- **Free:** `aqua` (Aqua), `mint` (Mint), `rosa` (Rosa), `orange` (Orange)
- **From the founder's rank Prime:** `amber` (Amber), `sky` (Sky blue), `coral` (Coral), `lime` (Lime), `ice` (Ice white), `lavender` (Lavender)

If the founder has at least the rank Prime, they can also turn on a **Gradient**. The tag then runs into a second colour. The founder sets the gradient and the second colour only in the clan menu under **Appearance**.

## Clan chat

- **Clan chat:** `/clanchat` or `/cc`, for all members
- **Officer chat:** `/officerchat` or `/oc`, only for the founder and officers

With a message, you write once into the channel. Without a message, the channel becomes your default. See [Chat](/guides/chat).

## Clan level

Your clan collects clan XP while your members play actively. With every level your clan grows. The clan menu shows your level and how much clan XP you need for the next one. When your clan reaches a new level, all members who are online get a notice.

A [Clan XP booster](/guides/inventory#boosters) doubles Clan XP for every clan on the network. Players without a clan can buy and activate one too. Multiple Clan boosters run one after another.

## Clan statistics

In the SMP and in Creative, `/stats` also shows clan values. `/stats <statistic> clans` shows the clan ranking. `/stats <statistic> clan [tag]` shows the values of one clan, without a tag your own. See [Account](/guides/account#commands).

## Clan log

`/clan log` shows the founder and officers what happened in the clan, newest first:

- members who joined, left or were removed
- changed roles and handed-over founding
- reached clan levels and new member limits
- accepted and declined applications
- sent, withdrawn and declined invitations

## Leave, hand over, disband

- **Leave:** `/clan leave`. As founder, you can only leave when nobody else is in the clan. The clan is then disbanded.
- **Hand over:** `/clan transfer <player>` makes a member the founder. You stay in the clan as an officer.
- **Disband:** `/clan disband`. All members leave the clan. Its name and tag are then locked for 30 days. You can found a new clan after 7 days.

## Commands

`<…>` and `[…]` are placeholders; `[…]` is optional, `a|b` means one of them.

### Find clans

- `/clans`: open the clan directory
- `/clans list`: show the directory
- `/clans search <text>`: search for a clan
- `/clans info <clan>`: information

### Join and found

- `/clan invitations`: your invitations
- `/clan accept <clan>`: accept an invitation
- `/clan decline <clan>`: decline an invitation
- `/clan apply <clan> [text]`: apply
- `/clan withdraw <clan>`: withdraw an application
- `/clan join <clan>`: join an open clan
- `/clan create <tag> <name>`: check tag and name
- `/clan found <tag> <name>`: found a clan

### Members

- `/clan`: open your clan
- `/clan info`: show your clan
- `/clan members`: show members
- `/clan leave`: leave the clan
- `/clanchat` or `/cc`: clan chat
- `/clan help`: all actions

### Officers

- `/clan invite <player>`: invite
- `/clan uninvite <player>`: withdraw an invitation
- `/clan applications`: show applications
- `/clan applications accept <player>`: accept an application
- `/clan applications decline <player>`: decline an application
- `/clan kick <player>`: remove a member
- `/clan bans`: show clan bans
- `/clan unban <player>`: lift a ban
- `/clan log`: clan log
- `/officerchat` or `/oc`: officer chat

Officers set the announcement for all members in the clan menu with `/clan`.

### Founder

- `/clan promote <player>`: promote
- `/clan demote <player>`: demote
- `/clan rename <name>`: change the name
- `/clan tag <tag>`: change the tag
- `/clan colour <colour>`: change the colour. Free: `aqua`, `mint`, `rosa`, `orange`. From the founder's rank Prime: `amber`, `sky`, `coral`, `lime`, `ice`, `lavender`.
- `/clan mode invite-only|request|open`: change how players join
- `/clan description [text]`: set the description
- `/clan members-public on|off`: show or hide the member list

- `/clan disband`: disband the clan

`/clan join`, `/clan leave`, `/clan kick`, `/clan transfer` and `/clan disband` ask first. Add `confirm` at the end to run them without asking, for example `/clan leave confirm`.

## Frequently asked questions

### How do I found a clan?

With `/clan found <tag> <name>`. You need a certain network level. More under [Found a clan](/guides/clans#found-a-clan).

### How do I join a clan?

Depending on the clan: accept an invitation with `/clan accept <clan>`, apply with `/clan apply <clan>` or join directly with `/clan join <clan>`.

### How do I find a clan?

`/clans` opens the directory. `/clans search <text>` searches.

### Why can I not leave the clan?

As founder, first hand over founding with `/clan transfer <player>` or disband the clan with `/clan disband`.

### Who may do what in the clan?

Members can leave the clan. Officers invite, decide applications, remove members, manage clan bans and set the announcement. The founder may do everything. More under [Roles](/guides/clans#roles).

### What happens when the founder stops playing?

They stay founder until they hand over founding or disband the clan. If their account is deleted, the officer who has been in the clan longest becomes founder. Without an officer, it is the member who has been in the clan longest.

### How does my clan get more room?

With every clan level, more members fit in. Your clan gains experience while you play actively.

### How do I change the colour or tag?

As founder with `/clan colour <colour>` and `/clan tag <tag>`. There are 10 colours: 4 are free, 6 are unlocked by the founder's rank, from Prime. More under [Colour](/guides/clans#colour).
