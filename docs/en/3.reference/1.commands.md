`<player>`, `<clan>` and `<message>` are placeholders. Replace them with a name or text, without typing the angle brackets. Some actions depend on your role or settings.

| Command                     | Purpose                                      |
| :-------------------------- | :------------------------------------------- |
| `/account`                  | Open your account                            |
| `/account messages`         | Open stored messages                         |
| `/profile [player]`         | Open your own or an available player profile |
| `/settings`                 | Open settings                                |
| `/settings dm`              | Manage direct message consent                |
| `/friends` or `/friend`     | Open friends                                 |
| `/friends add <player>`     | Send a friend request                        |
| `/friends requests`         | Show requests                                |
| `/friends accept <player>`  | Accept a request                             |
| `/friends decline <player>` | Decline a request                            |
| `/friends join <player>`    | Follow a friend                              |
| `/party`                    | Open your party                              |
| `/party invite <player>`    | Invite to your party                         |
| `/party accept <player>`    | Accept an invitation                         |
| `/party leave`              | Leave the party                              |
| `/partychat <message>`      | Write in party chat                          |
| `/msg <player> <message>`   | Send a direct message                        |
| `/r <message>`              | Reply                                        |
| `/block <player>`           | Block a player                               |
| `/unblock <player>`         | Unblock a player                             |
| `/blocked`                  | Show blocked players                         |
| `/clan`                     | Open your clan                               |
| `/clans`                    | Open the clan directory                      |
| `/clan apply <clan>`        | Apply to a clan                              |
| `/clanchat <message>`       | Write in clan chat                           |

Read more about [friends](/guides/friends), [parties](/guides/party), [messages](/guides/messages) and [clans](/guides/clans). This is a selection for players, rather than a list of every subcommand.
