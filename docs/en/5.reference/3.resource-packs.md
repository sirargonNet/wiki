## In the modpack

The official [modpack](https://sirargon.net/modpack) includes these resource packs and shaders:

- [Fresh Animations](https://modrinth.com/resourcepack/fresh-animations) and [Fresh Animations: Extensions](https://modrinth.com/resourcepack/fresh-animations-extensions)
- [Midnighttigger's Default Connected Textures](https://modrinth.com/resourcepack/mt-ct-d) and [Midnighttigger's Connected Textures Addons](https://modrinth.com/resourcepack/mt-ct-a)
- [Almost Vanilla Potions](https://modrinth.com/resourcepack/almost-vanilla-potions)
- [Blue Netherite](https://modrinth.com/resourcepack/blue-netherite)
- [Enchant Icons](https://modrinth.com/resourcepack/enchant-icons-countxd)
- [New Glowing Ores](https://modrinth.com/resourcepack/new-glowing-ores)
- [Redstone Tweaks](https://modrinth.com/resourcepack/redstone-tweaks)
- Shaders: [Complementary Shaders – Reimagined](https://modrinth.com/shader/complementary-reimagined) and [Complementary Shaders – Unbound](https://modrinth.com/shader/complementary-unbound), with Euphoria Patches

New packs are not turned on automatically in existing installations. Turn them on under **Options → Resource Packs**, and shaders under **Video Settings → Shader Packs**.

## Allowed

- Resource packs that only change the look, for example Fresh Animations, connected textures or clear glass
- New Glowing Ores

## Forbidden

- X-ray resource packs

## Frequently asked questions

### Why can I not enter an area?

Accept the resource pack. Set **Server Resource Packs** to **Enabled** in the server list.
