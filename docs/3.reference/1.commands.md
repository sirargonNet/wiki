---

`<Spieler>`, `<Clan>` und `<Nachricht>` sind Platzhalter. Ersetze sie durch den Namen oder Text, ohne die spitzen Klammern mitzuschreiben. Manche Aktionen hängen von deiner Rolle oder deinen Einstellungen ab.

| Befehl                       | Zweck                                         |
| :--------------------------- | :-------------------------------------------- |
| `/account`                   | Account öffnen                                |
| `/account messages`          | Gespeicherte Nachrichten öffnen               |
| `/profile [Spieler]`         | Eigenes oder verfügbares Spielerprofil öffnen |
| `/settings`                  | Einstellungen öffnen                          |
| `/settings dm`               | Zustimmung zu Direktnachrichten verwalten     |
| `/friends` oder `/friend`    | Freunde öffnen                                |
| `/friends add <Spieler>`     | Freundschaft anfragen                         |
| `/friends requests`          | Anfragen anzeigen                             |
| `/friends accept <Spieler>`  | Anfrage annehmen                              |
| `/friends decline <Spieler>` | Anfrage ablehnen                              |
| `/friends join <Spieler>`    | Einem Freund folgen                           |
| `/party`                     | Party öffnen                                  |
| `/party invite <Spieler>`    | Zur Party einladen                            |
| `/party accept <Spieler>`    | Einladung annehmen                            |
| `/party leave`               | Party verlassen                               |
| `/partychat <Nachricht>`     | In den Party-Chat schreiben                   |
| `/msg <Spieler> <Nachricht>` | Direktnachricht senden                        |
| `/r <Nachricht>`             | Antworten                                     |
| `/block <Spieler>`           | Spieler blockieren                            |
| `/unblock <Spieler>`         | Blockierung aufheben                          |
| `/blocked`                   | Blockierte anzeigen                           |
| `/clan`                      | Eigenen Clan öffnen                           |
| `/clans`                     | Clan-Verzeichnis öffnen                       |
| `/clan apply <Clan>`         | Bei einem Clan bewerben                       |
| `/clanchat <Nachricht>`      | In den Clan-Chat schreiben                    |

Mehr zu [Freunden](/guides/friends), [Partys](/guides/party), [Nachrichten](/guides/messages) und [Clans](/guides/clans). Die Übersicht zeigt eine Auswahl für Spieler; sie ist keine Liste aller Unterbefehle.
