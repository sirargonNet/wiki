title: 'Party'
description: 'Lade Freunde ein und spielt zusammen.'
icon: lucide:flag
---

Mit `/party` öffnest du deine Party. Eine Party hält eure Gruppe fürs gemeinsame Spielen zusammen.

| Befehl                     | Was er macht                                      |
| :------------------------- | :------------------------------------------------ |
| `/party create`            | Party erstellen                                   |
| `/party invite <Spieler>`  | Spieler einladen; bei Bedarf eine Party erstellen |
| `/party accept <Spieler>`  | Einladung annehmen                                |
| `/party decline <Spieler>` | Einladung ablehnen                                |
| `/party list`              | Mitglieder anzeigen                               |
| `/party leave`             | Party verlassen                                   |
| `/party leader <Spieler>`  | Leitung weitergeben, wenn du die Party leitest    |
| `/party kick <Spieler>`    | Mitglied entfernen, wenn du die Party leitest     |
| `/party disband`           | Party auflösen, wenn du sie leitest               |

Mit `/partychat <Nachricht>` schreibst du in den Party-Chat. `/party help` zeigt weitere Aktionen.
