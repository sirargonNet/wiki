Mit `/clan` öffnest du deinen Clan. Mit `/clans` entdeckst du andere Clans. Ein Clan hat einen Namen, ein Kürzel und eine Farbe. Du kannst immer nur in einem Clan sein.

Gründen kostet nichts, du brauchst dafür Netzwerk-Level 5. Mit Clan-XP steigt euer Clan im Level und bekommt Platz für mehr Mitglieder.

## Überblick

Das bringt dir ein Clan:

- **Kürzel:** steht farbig hinter deinem Namen
- **Online sehen:** wer online ist und auf welchem Server
- **Clan-Chat:** mit `/clanchat` oder `/cc`
- **Ankündigung:** eine Nachricht an alle Mitglieder
- **Nachspringen:** im Clan-Menü springst du zu Mitgliedern
- **Meldungen:** wenn Mitglieder online kommen

## Clans finden

`/clans` öffnet das Clan-Verzeichnis. Mit `/clans search <Text>` suchst du nach einem Teil von Name oder Kürzel. `/clans info <Clan>` zeigt Beitrittsart, Mitgliederzahl, Gründungsdatum und Gründer eines Clans. Die Mitgliederliste siehst du nur, wenn der Clan sie öffentlich zeigt.

## Beitreten

Wie du beitrittst, hängt von der Beitrittsart des Clans ab:

- **Nur Einladung:** Nur Gründer und Offiziere laden ein. `/clan accept <Clan>` nimmt eine Einladung an, `/clan decline <Clan>` lehnt sie ab.
- **Auf Anfrage:** Du bewirbst dich, Gründer oder Offiziere entscheiden. `/clan apply <Clan> [Text]` schickt eine Bewerbung, `/clan withdraw <Clan>` zieht sie zurück.
- **Offen:** Jeder kann beitreten. `/clan join <Clan>` tritt direkt bei.

`/clan invitations` zeigt deine Einladungen.

- Einladungen und Bewerbungen laufen nach 7 Tagen ab.
- Du kannst höchstens 5 offene Bewerbungen haben.
- Der Text einer Bewerbung hat höchstens 200 Zeichen. Du kannst ihn auch leer lassen.
- Die Antwort auf deine Bewerbung landet in deinen [Nachrichten](/guides/account#nachrichten). Lehnt der Clan im Clan-Menü ab, siehst du den Grund: **Clan ist voll**, **Passt nicht**, **Inaktiv** oder **Anderer Grund**.
- Trittst du einem Clan bei, enden deine anderen Bewerbungen und Einladungen.
- Ist ein Clan voll oder hat er dich gesperrt, kannst du nicht beitreten.

Von wem du Clan-Einladungen bekommst, stellst du in den [Einstellungen](/guides/settings#anfragen) ein. Bewerbungen, die du schickst, sind nie begrenzt.

## Gründen

1. `/clan create <Kürzel> <Name>` prüft, ob Kürzel und Name gültig und frei sind.
2. `/clan found <Kürzel> <Name>` gründet den Clan.

Das brauchst du:

- **Netzwerk-Level 5.** Mehr zum Level unter [Währungen & Streak](/guides/currencies#netzwerk-level).
- **Keinen Clan.** Du darfst in keinem anderen Clan sein.
- **Keine Wartezeit.** Hast du einen Clan aufgelöst oder als Gründer verlassen, gründest du erst nach 7 Tagen wieder. Beitreten kannst du in dieser Zeit trotzdem.

Die Gründung kostet nichts. Ein neuer Clan startet mit der Farbe Aqua, der Beitrittsart **Nur Einladung** und öffentlicher Mitgliederliste. Das änderst du danach im Clan-Menü.

## Name und Kürzel

| Regel   | Name                                               | Kürzel                      |
| :------ | :------------------------------------------------- | :-------------------------- |
| Länge   | 3 bis 20 Zeichen                                   | 2 bis 5 Zeichen             |
| Zeichen | Buchstaben a bis z, Ziffern, Leerzeichen, - und \_ | Buchstaben a bis z, Ziffern |

- Leerzeichen, `-` und `_` stehen nie am Anfang oder Ende und nie zweimal hintereinander.
- Groß- und Kleinschreibung zählt nicht. `ABC` und `abc` sind dasselbe Kürzel.
- Jeden Namen und jedes Kürzel gibt es nur einmal. Beleidigende Wörter sind nicht erlaubt.
- Der Gründer ändert Name und Kürzel mit `/clan rename <Name>` und `/clan tag <Kürzel>`. Danach geht das erst nach 30 Tagen wieder.
- Nach einer Umbenennung sind der alte Name und das alte Kürzel 30 Tage gesperrt. Nur euer eigener Clan darf sie in dieser Zeit zurücknehmen.
- Nach einer Auflösung sind Name und Kürzel 30 Tage für alle gesperrt, auch für den früheren Gründer.

## Rollen

Es gibt drei Rollen: **Gründer**, **Offizier** und **Mitglied**. Jeder Clan hat genau einen Gründer. Wie viele Offiziere es gibt, entscheidet der Gründer.

| Recht                                     | Mitglied | Offizier |  Gründer   |
| :---------------------------------------- | :------: | :------: | :--------: |
| Clan-Chat, Mitglieder sehen, nachspringen |    ✓     |    ✓     |     ✓      |
| Clan verlassen                            |    ✓     |    ✓     | nur allein |
| Spieler einladen, Einladung zurückziehen  |          |    ✓     |     ✓      |
| Bewerbungen annehmen oder ablehnen        |          |    ✓     |     ✓      |
| Mitglieder entfernen                      |          |    ✓     |     ✓      |
| Offiziere entfernen                       |          |          |     ✓      |
| Clan-Sperren ansehen und aufheben         |          |    ✓     |     ✓      |
| Ankündigung setzen                        |          |    ✓     |     ✓      |
| Clan-Protokoll ansehen                    |          |    ✓     |     ✓      |
| Offiziers-Chat                            |          |    ✓     |     ✓      |
| Offiziere ernennen und absetzen           |          |          |     ✓      |
| Name und Kürzel ändern                    |          |          |     ✓      |
| Farbe ändern                              |          |          |     ✓      |
| Beitrittsart ändern                       |          |          |     ✓      |
| Beschreibung setzen                       |          |          |     ✓      |
| Mitgliederliste zeigen oder verbergen     |          |          |     ✓      |
| Gründung übergeben                        |          |          |     ✓      |
| Clan auflösen                             |          |          |     ✓      |

**Mitglied**

- Clan verlassen: `/clan leave`

**Offizier**

- Spieler einladen: `/clan invite <Spieler>`, zurückziehen mit `/clan uninvite <Spieler>`
- Bewerbungen ansehen: `/clan applications`
- Bewerbungen annehmen oder ablehnen: `/clan applications accept <Spieler>` oder `/clan applications decline <Spieler>`
- Mitglieder entfernen: `/clan kick <Spieler>`. Offiziere können nur Mitglieder entfernen. In einem offenen Clan wird ein entferntes Mitglied auch gesperrt.
- Clan-Sperren ansehen und aufheben: `/clan bans`, `/clan unban <Spieler>`
- Ankündigung für alle Mitglieder setzen: im Clan-Menü mit `/clan`
- Clan-Protokoll ansehen: `/clan log`
- Offiziers-Chat: `/officerchat` oder `/oc`

**Gründer**

- alles, was Offiziere dürfen
- Offiziere entfernen: `/clan kick <Spieler>`
- Rollen ändern: `/clan promote <Spieler>`, `/clan demote <Spieler>`
- Name und Kürzel ändern: `/clan rename <Name>`, `/clan tag <Kürzel>`
- Farbe ändern: `/clan colour <Farbe>`
- Beitrittsart ändern: `/clan mode invite-only|request|open`
- Beschreibung setzen: `/clan description [Text]`
- Mitgliederliste zeigen oder verbergen: `/clan members-public on|off`
- Gründung übergeben: `/clan transfer <Spieler>`
- Clan auflösen: `/clan disband`

Wirst du ernannt oder abgesetzt, bekommst du eine [Nachricht](/guides/account#nachrichten). Wirst du als Offizier abgesetzt, enden die Einladungen, die du verschickt hast.

## Sperren

In einem offenen Clan wird ein entferntes Mitglied automatisch gesperrt. So kann es nicht sofort wieder beitreten. Gesperrte Spieler können dem Clan nicht beitreten und sich nicht bewerben. `/clan bans` zeigt alle Sperren mit Datum. `/clan unban <Spieler>` hebt eine Sperre auf.

## Ankündigung und Beschreibung

- **Ankündigung:** eine Nachricht für alle Mitglieder, höchstens 200 Zeichen. Sie steht in der Clan-Übersicht, mit Autor und Datum. Gründer und Offiziere setzen sie im Clan-Menü unter **Einstellungen**.
- **Beschreibung:** ein Satz für das Verzeichnis, höchstens 200 Zeichen. Der Gründer setzt sie mit `/clan description <Text>`. Ohne Text löscht `/clan description` sie.
- **Mitglieder öffentlich:** Mit `/clan members-public on|off` zeigt oder verbirgt der Gründer die Mitgliederliste im Verzeichnis.

Links sind in diesen Texten nur zu erlaubten Seiten möglich.

## Farbe

Der Gründer ändert die Farbe mit `/clan colour <Farbe>` oder im Clan-Menü unter **Aussehen**. Es gibt 10 Farben:

- **Frei:** `aqua` (Aqua), `mint` (Mint), `rosa` (Rosa), `orange` (Orange)
- **Ab dem Rang Prime des Gründers:** `amber` (Bernstein), `sky` (Himmelblau), `coral` (Koralle), `lime` (Limette), `ice` (Eisweiß), `lavender` (Lavendel)

Hat der Gründer mindestens den Rang Prime, kann er auch einen **Farbverlauf** einschalten. Dann läuft das Kürzel in eine zweite Farbe über. Den Farbverlauf und die zweite Farbe stellt er nur im Clan-Menü unter **Aussehen** ein.

## Clan-Chat

- **Clan-Chat:** `/clanchat` oder `/cc`, für alle Mitglieder
- **Offiziers-Chat:** `/officerchat` oder `/oc`, nur für Gründer und Offiziere

Mit Nachricht schreibst du einmal in den Kanal. Ohne Nachricht wird der Kanal dein Standard. Mehr unter [Chat](/guides/chat).

## Clan-Level

Euer Clan sammelt Clan-XP, wenn eure Mitglieder aktiv spielen. Mit jeder Stufe steigt euer Clan auf. Das Clan-Menü zeigt eure Stufe und wie viele Clan-XP bis zur nächsten fehlen. Erreicht euer Clan eine neue Stufe, bekommen alle Mitglieder, die gerade online sind, eine Meldung.

Ein [Clan-XP-Booster](/guides/inventory#booster) verdoppelt die Clan-XP für alle Clans im Netzwerk. Auch Spieler ohne Clan können ihn kaufen und aktivieren. Mehrere Clan-Booster laufen nacheinander.

Mit dem Level wächst das Mitgliederlimit:

| Stufe | Clan-XP insgesamt | Mitglieder |
| :---- | ----------------: | ---------: |
| 1     |                 0 |         16 |
| 2     |               700 |         16 |
| 3     |             1.600 |         16 |
| 4     |             2.700 |         16 |
| 5     |             4.000 |         24 |
| 6     |             5.400 |         24 |
| 7     |             6.900 |         24 |
| 8     |             8.500 |         24 |
| 9     |            10.200 |         24 |
| 10    |            12.000 |         32 |
| 11    |            14.200 |         32 |
| 12    |            16.900 |         32 |
| 13    |            20.100 |         32 |
| 14    |            23.800 |         32 |
| 15    |            28.000 |         32 |
| 16    |            32.700 |         32 |
| 17    |            37.900 |         32 |
| 18    |            43.600 |         32 |
| 19    |            49.800 |         32 |
| 20    |            56.500 |         40 |

Stufe 20 ist die höchste Stufe. Ist euer Clan voll, kommt niemand neu dazu. Bestehende Mitglieder verliert ihr nie.

## Clan-Statistiken

Im SMP und in Creative zeigt `/stats` auch Clan-Werte. `/stats <Statistik> clans` zeigt die Rangliste der Clans. `/stats <Statistik> clan [Kürzel]` zeigt die Werte eines Clans, ohne Kürzel deinen eigenen. Mehr unter [Account](/guides/account#befehle).

## Clan-Protokoll

`/clan log` zeigt Gründern und Offizieren, was im Clan passiert ist, neueste zuerst:

- Beitritte, Austritte und entfernte Mitglieder
- geänderte Rollen und übergebene Gründungen
- erreichte Clan-Stufen und neue Mitgliederlimits
- angenommene und abgelehnte Bewerbungen
- verschickte, zurückgezogene und abgelehnte Einladungen

## Verlassen, übergeben, auflösen

- **Verlassen:** `/clan leave`. Als Gründer verlässt du den Clan nur, wenn sonst niemand drin ist. Dann wird der Clan aufgelöst.
- **Übergeben:** `/clan transfer <Spieler>` macht ein Mitglied zum Gründer. Du bleibst als Offizier im Clan.
- **Auflösen:** `/clan disband`. Alle Mitglieder verlassen den Clan. Name und Kürzel sind danach 30 Tage gesperrt. Du gründest erst nach 7 Tagen wieder einen Clan.

## Befehle

`<…>` und `[…]` sind Platzhalter; `[…]` ist optional, `a|b` heißt: eins davon.

### Clans finden

- `/clans`: Clan-Verzeichnis öffnen
- `/clans list`: Verzeichnis anzeigen
- `/clans search <Text>`: Clan suchen
- `/clans info <Clan>`: Informationen

### Beitreten und gründen

- `/clan invitations`: deine Einladungen
- `/clan accept <Clan>`: Einladung annehmen
- `/clan decline <Clan>`: Einladung ablehnen
- `/clan apply <Clan> [Text]`: bewerben
- `/clan withdraw <Clan>`: Bewerbung zurückziehen
- `/clan join <Clan>`: offenem Clan beitreten
- `/clan create <Kürzel> <Name>`: Kürzel und Name prüfen
- `/clan found <Kürzel> <Name>`: Clan gründen

### Mitglieder

- `/clan`: Clan öffnen
- `/clan info`: Clan anzeigen
- `/clan members`: Mitglieder anzeigen
- `/clan leave`: Clan verlassen
- `/clanchat` oder `/cc`: Clan-Chat
- `/clan help`: alle Aktionen

### Offiziere

- `/clan invite <Spieler>`: einladen
- `/clan uninvite <Spieler>`: Einladung zurückziehen
- `/clan applications`: Bewerbungen anzeigen
- `/clan applications accept <Spieler>`: Bewerbung annehmen
- `/clan applications decline <Spieler>`: Bewerbung ablehnen
- `/clan kick <Spieler>`: Mitglied entfernen
- `/clan bans`: Clan-Sperren anzeigen
- `/clan unban <Spieler>`: Sperre aufheben
- `/clan log`: Clan-Protokoll
- `/officerchat` oder `/oc`: Offiziers-Chat

Die Ankündigung für alle Mitglieder setzen Offiziere im Clan-Menü mit `/clan`.

### Gründer

- `/clan promote <Spieler>`: befördern
- `/clan demote <Spieler>`: zurückstufen
- `/clan rename <Name>`: Name ändern
- `/clan tag <Kürzel>`: Kürzel ändern
- `/clan colour <Farbe>`: Farbe ändern. Frei: `aqua`, `mint`, `rosa`, `orange`. Ab dem Rang Prime des Gründers: `amber`, `sky`, `coral`, `lime`, `ice`, `lavender`.
- `/clan mode invite-only|request|open`: Beitrittsart ändern
- `/clan description [Text]`: Beschreibung setzen
- `/clan members-public on|off`: Mitgliederliste zeigen oder verbergen
- `/clan transfer <Spieler>`: Gründung übergeben
- `/clan disband`: Clan auflösen

`/clan join`, `/clan leave`, `/clan kick`, `/clan transfer` und `/clan disband` fragen vorher nach. Mit `confirm` am Ende führst du sie ohne Nachfrage aus, zum Beispiel `/clan leave confirm`.

## Häufige Fragen

### Wie gründe ich einen Clan?

Mit `/clan found <Kürzel> <Name>`. Du brauchst dafür ein bestimmtes Netzwerk-Level. Mehr unter [Gründen](/guides/clans#gründen).

### Wie trete ich einem Clan bei?

Je nach Clan: Einladung mit `/clan accept <Clan>` annehmen, mit `/clan apply <Clan>` bewerben oder mit `/clan join <Clan>` direkt beitreten.

### Wie finde ich einen Clan?

`/clans` öffnet das Verzeichnis. Mit `/clans search <Text>` suchst du.

### Warum kann ich den Clan nicht verlassen?

Als Gründer übergibst du zuerst die Gründung mit `/clan transfer <Spieler>` oder löst den Clan mit `/clan disband` auf.

### Wer darf was im Clan?

Mitglieder können den Clan verlassen. Offiziere laden ein, entscheiden Bewerbungen, entfernen Mitglieder, verwalten Clan-Sperren und setzen die Ankündigung. Der Gründer darf alles. Mehr unter [Rollen](/guides/clans#rollen).

### Was passiert, wenn der Gründer nicht mehr spielt?

Er bleibt Gründer, bis er die Gründung übergibt oder den Clan auflöst. Wird sein Konto gelöscht, wird der Offizier, der am längsten im Clan ist, Gründer. Gibt es keinen Offizier, ist es das Mitglied, das am längsten dabei ist.

### Wie bekommt mein Clan mehr Platz?

Mit jedem Clan-Level passen mehr Mitglieder hinein. Euer Clan sammelt Erfahrung, wenn ihr aktiv spielt.

### Wie ändere ich Farbe oder Kürzel?

Als Gründer mit `/clan colour <Farbe>` und `/clan tag <Kürzel>`. Es gibt 10 Farben: 4 sind frei, 6 schaltet der Rang des Gründers frei, ab Prime. Mehr unter [Farbe](/guides/clans#farbe).
