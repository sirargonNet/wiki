Ein Clan hat einen eigenen Namen, ein Kürzel und eine Farbe. Du kannst immer nur in einem Clan sein. Deinen Clan öffnest du mit `/clan`, andere Clans entdeckst du mit `/clans`.

Einen Clan zu gründen kostet nichts, dafür brauchst du Netzwerk-Level 5. Je mehr Clan-XP ihr sammelt, desto höher steigt euer Clan im Level und desto mehr Mitglieder passen hinein.

## Überblick

Das bringt dir ein Clan:

- Euer Kürzel steht farbig hinter deinem Namen.
- Du siehst, wer online ist und auf welchem Server.
- Ihr habt einen eigenen Clan-Chat mit `/clanchat` oder `/cc`.
- Eine Ankündigung erreicht alle Mitglieder.
- Im Clan-Menü springst du zu Mitgliedern nach.
- Du bekommst eine Meldung, wenn Mitglieder online kommen.

## Clans finden

`/clans` öffnet das Clan-Verzeichnis. Suchst du einen bestimmten Clan, reicht bei `/clans search <Text>` schon ein Teil vom Namen oder Kürzel. `/clans info <Clan>` zeigt dir Beitrittsart, Mitgliederzahl, Gründungsdatum und Gründer eines Clans. Die Mitgliederliste siehst du nur, wenn der Clan sie öffentlich zeigt.

## Beitreten

Wie du in einen Clan kommst, hängt von seiner Beitrittsart ab:

- **Nur Einladung:** Nur Gründer und Offiziere können dich einladen. Mit `/clan accept <Clan>` nimmst du die Einladung an, mit `/clan decline <Clan>` lehnst du sie ab.
- **Auf Anfrage:** Du schickst mit `/clan apply <Clan> [Text]` eine Bewerbung, und Gründer oder Offiziere entscheiden darüber. Mit `/clan withdraw <Clan>` ziehst du sie zurück.
- **Offen:** Jeder kann beitreten. Mit `/clan join <Clan>` bist du direkt drin.

Deine Einladungen siehst du mit `/clan invitations`.

- Einladungen und Bewerbungen laufen nach 7 Tagen ab.
- Du kannst höchstens 5 offene Bewerbungen haben.
- Deine Bewerbung kann einen Text mit bis zu 200 Zeichen haben, du kannst ihn aber auch leer lassen.
- Die Antwort auf deine Bewerbung bekommst du in deinen [Nachrichten](/guides/account#nachrichten). Lehnt der Clan dich im Clan-Menü ab, siehst du den Grund: **Clan ist voll**, **Passt nicht**, **Inaktiv** oder **Anderer Grund**.
- Sobald du einem Clan beitrittst, enden deine anderen Bewerbungen und Einladungen.
- Einem vollen Clan oder einem Clan, der dich gesperrt hat, kannst du nicht beitreten.

In den [Einstellungen](/guides/settings#anfragen) legst du fest, von wem du Clan-Einladungen bekommst. Diese Einstellung gilt nur für Einladungen an dich, deine eigenen Bewerbungen schränkt sie nicht ein.

## Gründen

1. Mit `/clan create <Kürzel> <Name>` prüfst du, ob Kürzel und Name gültig und noch frei sind.
2. Mit `/clan found <Kürzel> <Name>` gründest du den Clan.

Das brauchst du:

- **Netzwerk-Level 5.** Mehr zum Level findest du unter [Währungen & Streak](/guides/currencies#netzwerk-level).
- **Keinen Clan.** Du darfst in keinem anderen Clan sein.
- **Keine Wartezeit.** Hast du einen Clan aufgelöst oder als Gründer verlassen, kannst du erst nach 7 Tagen wieder einen gründen. Beitreten kannst du in der Zeit trotzdem.

Ein neuer Clan startet mit der Farbe Aqua, der Beitrittsart **Nur Einladung** und einer öffentlichen Mitgliederliste. Das kannst du danach im Clan-Menü ändern.

## Name und Kürzel

| Regel   | Name                                               | Kürzel                      |
| :------ | :------------------------------------------------- | :-------------------------- |
| Länge   | 3 bis 20 Zeichen                                   | 2 bis 5 Zeichen             |
| Zeichen | Buchstaben a bis z, Ziffern, Leerzeichen, - und \_ | Buchstaben a bis z, Ziffern |

- Leerzeichen, `-` und `_` dürfen nie am Anfang oder Ende stehen und nie zweimal hintereinander.
- Groß- und Kleinschreibung spielt keine Rolle: `ABC` und `abc` sind dasselbe Kürzel.
- Jeden Namen und jedes Kürzel gibt es nur einmal, und beleidigende Wörter sind nicht erlaubt.
- Der Gründer ändert Name und Kürzel mit `/clan rename <Name>` und `/clan tag <Kürzel>`. Danach geht das erst nach 30 Tagen wieder.
- Nach einer Umbenennung bleiben der alte Name und das alte Kürzel 30 Tage gesperrt. In der Zeit darf nur euer eigener Clan sie zurücknehmen.
- Wird ein Clan aufgelöst, sind Name und Kürzel 30 Tage für alle gesperrt, auch für den früheren Gründer.

## Rollen

Es gibt drei Rollen: **Gründer**, **Offizier** und **Mitglied**. Jeder Clan hat genau einen Gründer, und er entscheidet, wie viele Offiziere es gibt.

| Recht                                     | Mitglied | Offizier |  Gründer   |
| :---------------------------------------- | :------: | :------: | :--------: |
| Clan-Chat, Mitglieder sehen, nachspringen |    ✓     |    ✓     |     ✓      |
| Clan verlassen                            |    ✓     |    ✓     | nur allein |
| Spieler einladen, Einladung zurückziehen  |          |    ✓     |     ✓      |
| Bewerbungen annehmen oder ablehnen        |          |    ✓     |     ✓      |
| Mitglieder entfernen                      |          |    ✓     |     ✓      |
| Offiziere entfernen                       |          |          |     ✓      |
| Clan-Sperren ansehen und aufheben         |          |    ✓     |     ✓      |
| Ankündigung setzen                        |          |    ✓     |     ✓      |
| Clan-Protokoll ansehen                    |          |    ✓     |     ✓      |
| Offiziers-Chat                            |          |    ✓     |     ✓      |
| Offiziere ernennen und absetzen           |          |          |     ✓      |
| Name und Kürzel ändern                    |          |          |     ✓      |
| Farbe ändern                              |          |          |     ✓      |
| Beitrittsart ändern                       |          |          |     ✓      |
| Beschreibung setzen                       |          |          |     ✓      |
| Mitgliederliste zeigen oder verbergen     |          |          |     ✓      |
| Gründung übergeben                        |          |          |     ✓      |
| Clan auflösen                             |          |          |     ✓      |

**Mitglied**

- Clan verlassen: `/clan leave`

**Offizier**

- Spieler einladen: `/clan invite <Spieler>`, zurückziehen mit `/clan uninvite <Spieler>`
- Bewerbungen ansehen: `/clan applications`
- Bewerbungen annehmen oder ablehnen: `/clan applications accept <Spieler>` oder `/clan applications decline <Spieler>`
- Mitglieder entfernen: `/clan kick <Spieler>`. Offiziere können nur Mitglieder entfernen. In einem offenen Clan wird ein entferntes Mitglied auch [gesperrt](/guides/clans#sperren).
- Clan-Sperren ansehen und aufheben: `/clan bans`, `/clan unban <Spieler>`
- Ankündigung für alle Mitglieder setzen: im Clan-Menü mit `/clan`
- Clan-Protokoll ansehen: `/clan log`
- Offiziers-Chat: `/officerchat` oder `/oc`

**Gründer**

- alles, was Offiziere dürfen
- Offiziere entfernen: `/clan kick <Spieler>`
- Rollen ändern: `/clan promote <Spieler>`, `/clan demote <Spieler>`
- Name und Kürzel ändern: `/clan rename <Name>`, `/clan tag <Kürzel>`
- Farbe ändern: `/clan colour <Farbe>`
- Beitrittsart ändern: `/clan mode invite-only|request|open`
- Beschreibung setzen: `/clan description [Text]`
- Mitgliederliste zeigen oder verbergen: `/clan members-public on|off`
- Gründung übergeben: `/clan transfer <Spieler>`
- Clan auflösen: `/clan disband`

Wirst du ernannt oder abgesetzt, bekommst du eine [Nachricht](/guides/account#nachrichten). Verlierst du dabei deinen Platz als Offizier, enden die Einladungen, die du verschickt hast.

## Sperren

Wird in einem offenen Clan ein Mitglied entfernt, ist es automatisch gesperrt und kann deshalb nicht sofort wieder beitreten. Gesperrte Spieler können dem Clan weder beitreten noch sich bewerben. `/clan bans` zeigt alle Sperren mit Datum, und mit `/clan unban <Spieler>` hebst du eine Sperre auf.

## Ankündigung und Beschreibung

- **Ankündigung:** eine Nachricht an alle Mitglieder mit höchstens 200 Zeichen. Sie steht mit Autor und Datum in der Clan-Übersicht. Gründer und Offiziere setzen sie im Clan-Menü unter **Einstellungen**.
- **Beschreibung:** ein Satz fürs Verzeichnis, höchstens 200 Zeichen. Der Gründer setzt sie mit `/clan description <Text>`, und `/clan description` ohne Text löscht sie wieder.
- **Mitglieder öffentlich:** Mit `/clan members-public on|off` zeigt oder verbirgt der Gründer die Mitgliederliste im Verzeichnis.

Links kannst du in diesen Texten nur zu erlaubten Seiten setzen.

## Farbe

Der Gründer ändert die Farbe mit `/clan colour <Farbe>` oder im Clan-Menü unter **Aussehen**. Es gibt 10 Farben:

- **Frei:** `aqua` (Aqua), `mint` (Mint), `rosa` (Rosa), `orange` (Orange)
- **Ab dem Rang Prime des Gründers:** `amber` (Bernstein), `sky` (Himmelblau), `coral` (Koralle), `lime` (Limette), `ice` (Eisweiß), `lavender` (Lavendel)

Hat der Gründer mindestens den Rang Prime, kann er außerdem einen **Farbverlauf** einschalten, bei dem das Kürzel in eine zweite Farbe übergeht. Den Verlauf und die zweite Farbe stellt er nur im Clan-Menü unter **Aussehen** ein.

## Clan-Chat

- **Clan-Chat:** `/clanchat` oder `/cc`, für alle Mitglieder
- **Offiziers-Chat:** `/officerchat` oder `/oc`, nur für Gründer und Offiziere

Hängst du eine Nachricht an, schreibst du einmal in den Kanal. Ohne Nachricht wird der Kanal dein Standard. Mehr dazu unter [Chat](/guides/chat).

## Clan-Level

Euer Clan sammelt Clan-XP, während eure Mitglieder aktiv spielen, und steigt damit Stufe für Stufe auf. Im Clan-Menü siehst du eure Stufe und wie viele Clan-XP bis zur nächsten noch fehlen. Erreicht ihr eine neue Stufe, bekommen alle Mitglieder, die gerade online sind, eine Meldung.

Ein [Clan-XP-Booster](/guides/inventory#booster) verdoppelt die Clan-XP für alle Clans im Netzwerk, und auch Spieler ohne Clan können ihn kaufen und aktivieren. Mehrere Clan-Booster laufen nacheinander.

Mit dem Level wächst das Mitgliederlimit:

| 1     |                 0 |         16 |
| 2     |               700 |         16 |
| 3     |             1.600 |         16 |
| 4     |             2.700 |         16 |
| 5     |             4.000 |         24 |
| 6     |             5.400 |         24 |
| 7     |             6.900 |         24 |
| 8     |             8.500 |         24 |
| 9     |            10.200 |         24 |
| 10    |            12.000 |         32 |
| 11    |            14.200 |         32 |
| 12    |            16.900 |         32 |
| 13    |            20.100 |         32 |
| 14    |            23.800 |         32 |
| 15    |            28.000 |         32 |
| 16    |            32.700 |         32 |
| 17    |            37.900 |         32 |
| 18    |            43.600 |         32 |
| 19    |            49.800 |         32 |

Stufe 20 ist die höchste Stufe. Ist euer Clan voll, kommt niemand Neues dazu, aber Mitglieder, die schon drin sind, verliert ihr nie.

## Clan-Statistiken

Im SMP und in Creative zeigt `/stats` auch Clan-Werte. Mit `/stats <Statistik> clans` siehst du die Rangliste der Clans, mit `/stats <Statistik> clan [Kürzel]` die Werte eines Clans. Lässt du das Kürzel weg, sind es die deines eigenen Clans. Mehr unter [Account](/guides/account#befehle).

## Clan-Protokoll

`/clan log` zeigt Gründern und Offizieren, was im Clan passiert ist, das Neueste zuerst:

- Beitritte, Austritte und entfernte Mitglieder
- geänderte Rollen und übergebene Gründungen
- erreichte Clan-Stufen und neue Mitgliederlimits
- angenommene und abgelehnte Bewerbungen
- verschickte, zurückgezogene und abgelehnte Einladungen

## Verlassen, übergeben, auflösen

- **Verlassen:** `/clan leave`. Als Gründer kannst du den Clan nur verlassen, wenn sonst niemand mehr drin ist. Der Clan wird dann aufgelöst.
- **Übergeben:** `/clan transfer <Spieler>` macht ein Mitglied zum Gründer, und du bleibst als Offizier im Clan.
- **Auflösen:** `/clan disband`. Alle Mitglieder verlassen den Clan, und Name und Kürzel sind danach 30 Tage gesperrt. Einen neuen Clan gründest du erst nach 7 Tagen wieder.

## Befehle

`<…>` und `[…]` sind Platzhalter; `[…]` ist optional, `a|b` heißt: eins davon.

### Clans finden

- `/clans`: Clan-Verzeichnis öffnen
- `/clans list`: Verzeichnis anzeigen
- `/clans search <Text>`: Clan suchen
- `/clans info <Clan>`: Informationen

### Beitreten und gründen

- `/clan invitations`: deine Einladungen
- `/clan accept <Clan>`: Einladung annehmen
- `/clan decline <Clan>`: Einladung ablehnen
- `/clan apply <Clan> [Text]`: bewerben
- `/clan withdraw <Clan>`: Bewerbung zurückziehen
- `/clan join <Clan>`: offenem Clan beitreten
- `/clan create <Kürzel> <Name>`: Kürzel und Name prüfen
- `/clan found <Kürzel> <Name>`: Clan gründen

### Mitglieder

- `/clan`: Clan öffnen
- `/clan info`: Clan anzeigen
- `/clan members`: Mitglieder anzeigen
- `/clan leave`: Clan verlassen
- `/clanchat` oder `/cc`: Clan-Chat
- `/clan help`: alle Aktionen

### Offiziere

- `/clan invite <Spieler>`: einladen
- `/clan uninvite <Spieler>`: Einladung zurückziehen
- `/clan applications`: Bewerbungen anzeigen
- `/clan applications accept <Spieler>`: Bewerbung annehmen
- `/clan applications decline <Spieler>`: Bewerbung ablehnen
- `/clan kick <Spieler>`: Mitglied entfernen
- `/clan bans`: Clan-Sperren anzeigen
- `/clan unban <Spieler>`: Sperre aufheben
- `/clan log`: Clan-Protokoll
- `/officerchat` oder `/oc`: Offiziers-Chat

Die Ankündigung für alle Mitglieder setzen Offiziere im Clan-Menü mit `/clan`.

### Gründer

- `/clan promote <Spieler>`: befördern
- `/clan demote <Spieler>`: zurückstufen
- `/clan rename <Name>`: Name ändern
- `/clan tag <Kürzel>`: Kürzel ändern
- `/clan colour <Farbe>`: Farbe ändern. Frei: `aqua`, `mint`, `rosa`, `orange`. Ab dem Rang Prime des Gründers: `amber`, `sky`, `coral`, `lime`, `ice`, `lavender`.
- `/clan mode invite-only|request|open`: Beitrittsart ändern
- `/clan description [Text]`: Beschreibung setzen
- `/clan members-public on|off`: Mitgliederliste zeigen oder verbergen
- `/clan transfer <Spieler>`: Gründung übergeben
- `/clan disband`: Clan auflösen

`/clan join`, `/clan leave`, `/clan kick`, `/clan transfer` und `/clan disband` fragen vorher nach. Hängst du `confirm` ans Ende, laufen sie ohne Nachfrage, zum Beispiel `/clan leave confirm`.

## Häufige Fragen

### Wie gründe ich einen Clan?

Mit `/clan found <Kürzel> <Name>`, dafür brauchst du aber ein bestimmtes Netzwerk-Level. Alles Weitere steht unter [Gründen](/guides/clans#gründen).

### Wie trete ich einem Clan bei?

Das hängt vom Clan ab: Du nimmst eine Einladung mit `/clan accept <Clan>` an, bewirbst dich mit `/clan apply <Clan>` oder trittst mit `/clan join <Clan>` direkt bei.

### Wie finde ich einen Clan?

`/clans` öffnet das Verzeichnis, und mit `/clans search <Text>` suchst du darin.

### Warum kann ich den Clan nicht verlassen?

Als Gründer übergibst du zuerst die Gründung mit `/clan transfer <Spieler>` oder löst den Clan mit `/clan disband` auf.

### Wer darf was im Clan?

Mitglieder können den Clan verlassen. Offiziere laden ein, entscheiden Bewerbungen, entfernen Mitglieder, verwalten Clan-Sperren und setzen die Ankündigung. Der Gründer darf alles. Mehr unter [Rollen](/guides/clans#rollen).

### Was passiert, wenn der Gründer nicht mehr spielt?

Er bleibt Gründer, bis er die Gründung übergibt oder den Clan auflöst. Wird sein Konto gelöscht, wird der Offizier Gründer, der am längsten im Clan ist. Gibt es keinen Offizier, rückt das Mitglied nach, das am längsten dabei ist.

### Wie bekommt mein Clan mehr Platz?

Euer Clan sammelt Clan-XP, während ihr spielt. Auf bestimmten Clan-Levels passen mehr Mitglieder hinein, die Tabelle unter [Clan-Level](/guides/clans#clan-level) zeigt, wo.

### Wie ändere ich Farbe oder Kürzel?

Als Gründer mit `/clan colour <Farbe>` und `/clan tag <Kürzel>`. 4 der 10 Farben sind frei, die anderen 6 gibt es, sobald der Gründer mindestens Prime ist. Mehr unter [Farbe](/guides/clans#farbe).
