## So kommst du ins Spiel

1. Starte Minecraft: Java Edition **26.3**. **26.2** wird ebenfalls unterstützt.
2. Öffne **Mehrspieler** und füge einen Server hinzu.
3. Trag `sirargon.net` als Adresse ein und verbinde dich.

## Mit oder ohne Mods

Du kannst ohne Voice-Mod mitspielen. Wenn du mit anderen im Spiel reden möchtest, nutze das offizielle Modpack [Sirargons Mod-Mische](https://modrinth.com/modpack/sirargons-mod-mische). Simple Voice Chat ist schon enthalten.

Mehr dazu unter [Voice-Chat](/guides/voice-chat).

## Nächste Schritte

Schau dir die [Spielmodi](/guides/game-modes) an. Mit `/account` öffnest du deinen [Account](/guides/account) im Spiel.

## Checkliste

- [ ] Java Edition in einer unterstützten Version gestartet
- [ ] `sirargon.net` hinzugefügt
- [ ] Optional das offizielle Modpack für Voice-Chat eingerichtet
