## SMP-XP

SMP-XP bekommst du, wenn du im SMP etwas tust. Die Aktionsleiste zeigt dir, wie viel gerade dazukommt.

### So wird gezählt

- Während du spielst, zählt der Server deine Aktionen mit.
- Alle paar Sekunden werden sie gebucht. Darum kommen deine XP kurz nach der Aktion an.
- AFK-Zeit zählt nicht. Zeit im Team-Dienst und während einer Wartung zählt auch nicht.
- Hat der Server kurz eine Störung, gehen deine Aktionen nicht verloren. Sie werden nachgebucht.

### Aktionen

| Aktion                                   | So viel bringt es                                                               |
| :--------------------------------------- | :------------------------------------------------------------------------------ |
| aktiv spielen                            | mit der Zeit ein wenig                                                          |
| Erze abbauen                             | je seltener das Erz, desto mehr; Diamant, Smaragd und Antiker Schutt am meisten |
| Gestein, Erde, Sand und Kies abbauen     | wenig pro Block                                                                 |
| Bäume fällen                             | etwas pro Stamm                                                                 |
| Feldfrüchte ernten                       | wenig pro reifer Pflanze; Kürbis und Melone etwas mehr                          |
| Mobs besiegen                            | je stärker der Mob, desto mehr; Großer Wächter, Warden und Wither sehr viel     |
| Items aus dem Ofen nehmen                | abhängig von der Ofen-XP des Items                                              |
| neue Chunks und Biome entdecken          | einmal pro Chunk und Biom                                                       |
| eine Struktur als Erster betreten        | einmal pro Struktur; je größer, desto mehr                                      |
| ein Advancement zum ersten Mal erreichen | je nach Art des Advancements                                                    |

- Selbst gesetzte Blöcke und unreife Pflanzen zählen nicht. AFK zählt nicht.
- Farmst du lange dieselbe Mob-Art oder schmilzt du sehr viel auf einmal, bekommst du eine Weile weniger XP. Auch das Entdecken neuer Chunks hat eine Grenze pro Stunde.
- Mobs aus den Spawnern der Prüfungskammern bringen weniger XP.
- Einen Mob bekommt der Spieler, der ihm den meisten Schaden gemacht hat. Er muss kurz nach deinem letzten Treffer sterben. Feuer, Fallschaden und andere Mobs zählen nicht. Das gilt auch für Kill-Quests.
- Mit einem SMP-XP-Booster aus deinem [Inventar](/guides/account) bekommst du doppelte SMP-XP.

## Level

Mit genug SMP-XP steigt dein SMP-Level. Ab Level 2 bekommst du pro Level einen Skillpunkt. Ein Höchstlevel gibt es nicht.

Ab Level 21 kostet jedes Level 20 XP mehr als das vorige: Level 21 kostet 300 XP, Level 22 kostet 320 XP und so weiter.
