`/milestones` zeigt einmalige Meilensteine. Jeder bringt dir einmal Silber. Oben wählst du das Realm, darunter stehen seine Meilensteine. Erreichte Meilensteine sind dunkler.

## Oberwelt

### Start

| Meilenstein    | Aufgabe                           |    Belohnung |
| :------------- | :-------------------------------- | -----------: |
| Erste Schritte | Öffne `/skills`.                  |   200 Silber |
| Erster Stern   | Gib deinen ersten Skillpunkt aus. |   500 Silber |
| Eigenes Camp   | Gründe ein [Camp](/smp/camps).    | 1.000 Silber |
| Erste Quest    | Schließe eine Tagesquest ab.      |   300 Silber |
| Wochenwerk     | Schließe eine Wochenquest ab.     | 1.000 Silber |
| Durchs Tor     | Betritt den Nether.               | 1.000 Silber |

Für **Erste Quest** und **Wochenwerk** zählen nur Quests der Oberwelt.

### Level

| Meilenstein  | Aufgabe                              |     Belohnung |
| :----------- | :----------------------------------- | ------------: |
| SMP-Level 5  | Erreiche SMP-Level 5.                |  1.000 Silber |
| SMP-Level 10 | Erreiche SMP-Level 10.               |  2.000 Silber |
| SMP-Level 20 | Erreiche SMP-Level 20.               |  5.000 Silber |
| SMP-Level 30 | Erreiche SMP-Level 30.               | 10.000 Silber |
| Level 40     | Sammle 11.650 SMP-XP, etwa Level 40. | 10.000 Silber |
| Level 50     | Sammle 19.550 SMP-XP, etwa Level 50. | 10.000 Silber |

Mehr zu XP und Level steht unter [Level und XP](/smp/skills#level-und-xp).

Bei diesen Meilensteinen entdeckst du den Ort und erreichst seinen Fortschritt.

| Meilenstein           | Aufgabe                            |     Belohnung |
| :-------------------- | :--------------------------------- | ------------: |
| Plünderer-Außenposten | Finde einen Plünderer-Außenposten. |  5.000 Silber |
| Ozeanmonument         | Finde ein Ozeanmonument.           |  5.000 Silber |
| Antike Stadt          | Finde eine Antike Stadt.           |  5.000 Silber |
| Prüfungskammern       | Finde Prüfungskammern.             |  5.000 Silber |
| Waldanwesen           | Finde ein Waldanwesen.             | 10.000 Silber |

| Erste Lohe             | Besiege eine Lohe.                                                                     |  1.000 Silber |
| Lavareiter             | Reite auf einem Schreiter.                                                             |  1.000 Silber |
| Antiker Fund           | Baue Antiken Schutt ab.                                                                |  2.000 Silber |
| Seelensandtal          | Entdecke das Seelensandtal.                                                            |  5.000 Silber |
| Basaltdeltas           | Entdecke die Basaltdeltas.                                                             |  2.000 Silber |
| Karmesinwald           | Entdecke den Karmesinwald.                                                             |  5.000 Silber |

| Incendium-Entdeckung   | Entdecke einen besonderen Ort von Incendium im Nether und erreiche seinen Fortschritt. |  5.000 Silber |
