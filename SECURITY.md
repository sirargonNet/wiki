# Security Policy

## Scope

This private repository contains the sirargon.net player wiki and its publishing
automation. The website runtime belongs to `mc-network/apps/wiki`. Security
corrections are made on the current content branch and published in a new wiki
release; published tags are immutable.

## Reporting

Report vulnerabilities privately to [titus.kirch@kirch.dev](mailto:titus.kirch@kirch.dev).
Include the affected file or version, impact and reproduction steps. Never put
credentials or personal data into wiki pages or issue reports.
